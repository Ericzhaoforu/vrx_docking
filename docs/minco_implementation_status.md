# MINCO-USV Implementation Status

## Current objective
Implement strict GCOPTER-style MINCO-S3NU trajectory generation for the USV flat output

\[
z = [x, y, \psi]^T.
\]

This module must produce a `FeasibleReference`-compatible local trajectory for the existing flatness-MPC/NMPC tracker.

## Current integration status

- MINCO is available as runtime one-shot local reference generation through
  `reference_source := minco`.
- The controller creates the MINCO reference once when the active reference is
  `None`; the NMPC then tracks that fixed reference online.
- Continuous online MINCO replanning is not implemented yet. Missing pieces are
  replan triggers, previous-MINCO warm start, continuation scheduling during
  runtime, safe reference replacement, and failed-replan handling.
- Dense penalty gradients are now analytic at the quadrature node and
  coefficient/time levels. Finite differences are retained only for tests and
  audit utilities.

## Phase 4 implementation evidence

Implemented:

- `robotx_safe_docking_control/robotx_safe_docking_control/minco_usv_optimizer.py`
- `MincoUsvOptimizerConfig`
- `MincoUsvOptimizerResult`
- `MincoUsvOptimizer`

Implemented optimizer behavior:

- sparse outer variables are only `vec(inPs)` and `theta`;
- coefficients are regenerated through `MINCO_S3NU.set_parameters(inPs, ts)`;
- fixed-total-time mode uses softmax segment times:
  `T_i = T_s exp(theta_i) / sum_j exp(theta_j)`;
- free-total-time mode uses positive segment times via
  `T_i = min_segment_time + exp(theta_i)`;
- objective combines strict MINCO jerk energy, optional free-time
  regularization, and Phase 3 dense quadrature penalties;
- gradients combine direct coefficient/time gradients and use the MINCO adjoint
  to propagate to `inPs` and `ts`, then apply the softmax chain rule to
  `theta`.

- `reference_source := minco` builds a strict MINCO local reference from the
  current controller state `z,z_dot`, using a local terminal offset selected by

- The generated MINCO trajectory is exported into the existing

  through `horizon_at_offsets(...)`.

- No PID fallback, front-end planner, obstacle corridor, ESDF, costmap, or NN
  residual compensation was added.

Boundary acceleration policy:

- The controller does not read acceleration from odometry or state estimation.
- MINCO start acceleration is selected by the required fallback chain:
  previous accepted MINCO reference acceleration, previous NMPC predicted
  acceleration, nominal dynamics from the last applied differential-thrust
  command, then zero for the first run.
- The acados result extraction now computes `z_ddot_pred` from nominal USV
  dynamics and the predicted generalized force, so the previous-NMPC fallback
  is meaningful for both acados and SLSQP paths.
- MINCO reference diagnostics include
  `minco_boundary_acceleration_source_id`:
  `1=previous_minco`, `2=previous_mpc`, `3=last_command`, `4=zero`.

## Phase 8 implementation and validation evidence

  inequality values and avoids eager `np.where(...)` overflow in the softplus
  branch.

  directly.

The implemented flatness inverse uses:

```text
u = cos(psi) * x_dot + sin(psi) * y_dot
v = -sin(psi) * x_dot + cos(psi) * y_dot
r = psi_dot
```

and:

```text
u_dot = cos(psi) * x_ddot + sin(psi) * y_ddot + r * v
v_dot = -sin(psi) * x_ddot + cos(psi) * y_ddot - r * u
r_dot = psi_ddot
```

Substitution into the nominal model cancels the Coriolis terms in surge and
sway. The generalized forces used by the dense penalties are therefore:

```text
tau_u = m * (cos(psi) * x_ddot + sin(psi) * y_ddot)
        + du * u + duu * abs(u) * u
tau_v = m * (-sin(psi) * x_ddot + cos(psi) * y_ddot)
        + dv * v + dvv * abs(v) * v
tau_r = Iz * psi_ddot + dr * r + drr * abs(r) * r
```

The differential-thrust actuator constraints are applied through:

```text
T_L = 0.5 * (tau_u - tau_r / l)
T_R = 0.5 * (tau_u + tau_r / l)
T_min <= T_L,T_R <= T_max
```

Dense penalty gradient formula:

```text
For one quadrature node s = alpha * T:

J_q = T * w * f(z(s), z_dot(s), z_ddot(s))

dJ_q/dC =
  T * w * (
    outer(B0, grad_z)
    + outer(B1, grad_z_dot)
    + outer(B2, grad_z_ddot)
  )

dJ_q/dT =
  w * f
  + T * w * alpha * (
    grad_z dot z_dot
    + grad_z_dot dot z_ddot
    + grad_z_ddot dot z_jerk
  )
```

These are direct gradients with respect to polynomial coefficients and segment
times at fixed coefficients. The existing MINCO adjoint then propagates them to
the sparse outer variables `inPs` and `theta`.
