# Final MINCO-USV Trajectory Generator Formulation and Codex Implementation Plan

## 0. Key design decision

We follow the strict GCOPTER/MINCO structure:

- The optimized sparse variables are intermediate flat-output points and segment times.
- Polynomial coefficients are **not** optimized directly.
- For given intermediate points and segment times, coefficients are generated by the MINCO-S3NU optimality-condition linear system.
- Continuous constraints are written in the original constrained problem, then implemented through dense quadrature penalty terms in the unconstrained MINCO optimization.

For this USV project, the flat output is:

```math
z(t)=
\begin{bmatrix}
x(t) & y(t) & \psi(t)
\end{bmatrix}^{T}
\in\mathbb R^3
```

The first implementation uses minimum jerk MINCO-S3NU.

Current implementation status:

- MINCO is integrated as runtime one-shot local reference generation through
  `reference_source := minco`.
- Continuous online MINCO replanning is not implemented yet.
- The active optimizer uses analytic dense-penalty gradients. Finite
  differences are retained only for tests and audit utilities.

## 1. Original piecewise trajectory optimization problem

The trajectory has \(M\) pieces. Piece \(i\) is defined on local time \(s\in[0,T_i]\):

\[
z_i(s)=\begin{bmatrix}x_i(s)\\y_i(s)\\\psi_i(s)\end{bmatrix}.
\]

The global breakpoints are

\[
t_0=0,\qquad t_i=\sum_{\ell=1}^{i}T_\ell,
\]

and the total time is

\[
T_s=\sum_{i=1}^{M}T_i,\qquad T_i>0.
\]

The global trajectory is

\[
z(t)=z_i(t-t_{i-1}),\qquad t\in[t_{i-1},t_i].
\]

### 1.1 Original constrained problem

\[
\begin{aligned}
\min_{\{z_i(\cdot)\}_{i=1}^{M},\{T_i\}_{i=1}^{M}}
\quad
J_{\mathrm{orig}}
&=J_{\mathrm{smooth}}+J_{\mathrm{time}}\\
\mathrm{s.t.}\quad
&z_1(0)=z_0,\\
&\dot z_1(0)=\dot z_0,\\
&\ddot z_1(0)=\ddot z_0,\\
&z_M(T_M)=z_f,\\
&\dot z_M(T_M)=\dot z_f,\\
&\ddot z_M(T_M)=\ddot z_f,\\
&z_i(T_i)=z_{i+1}(0),\quad i=1,\ldots,M-1,\\
&\dot z_i(T_i)=\dot z_{i+1}(0),\quad i=1,\ldots,M-1,\\
&\ddot z_i(T_i)=\ddot z_{i+1}(0),\quad i=1,\ldots,M-1,\\
&T_s=\sum_{i=1}^{M}T_i,\\
&T_i>0,\quad i=1,\ldots,M,\\
&|\tau_v(s)|\le \bar\tau_v,\quad s\in[0,T_i],\\
&u_{\min}\le u(s)\le u_{\max},\quad s\in[0,T_i],\\
&|v(s)|\le v_{\max},\quad s\in[0,T_i],\\
&|r(s)|\le r_{\max},\quad s\in[0,T_i],\\
&|\dot u(s)|\le a_{u,\max},\quad s\in[0,T_i],\\
&|\dot v(s)|\le a_{v,\max},\quad s\in[0,T_i],\\
&|\dot r(s)|\le a_{r,\max},\quad s\in[0,T_i],\\
&T_{\min}\le \frac12\left(\tau_u(s)-\frac{\tau_r(s)}{l}\right)\le T_{\max},\quad s\in[0,T_i],\\
&T_{\min}\le \frac12\left(\tau_u(s)+\frac{\tau_r(s)}{l}\right)\le T_{\max},\quad s\in[0,T_i].
\end{aligned}
\]

The original cost only contains smoothness and optional time regularization.

### 1.2 Smoothness cost

\[
J_{\mathrm{smooth}}
=
w_s\sum_{i=1}^{M}\int_0^{T_i}\|z_i^{(3)}(s)\|^2ds.
\]

### 1.3 Time cost

If total time is fixed, \(T_s\) is a given constant and

\[
J_{\mathrm{time}}=0.
\]

If total time is free,

\[
J_{\mathrm{time}}=\rho_TT_s=\rho_T\sum_{i=1}^{M}T_i.
\]

## 2. USV flatness inverse and constraints

Define

```math
R_3(\psi)=
\begin{bmatrix}
\cos\psi&-\sin\psi&0\\
\sin\psi&\cos\psi&0\\
0&0&1
\end{bmatrix}
```

Body velocity:

```math
\nu=
\begin{bmatrix}
u & v & r
\end{bmatrix}^{T}
=
R_3(\psi)^T\dot z
```

Equivalently,

```math
\begin{aligned}
u &= \dot x\cos\psi+\dot y\sin\psi \\
v &= -\dot x\sin\psi+\dot y\cos\psi \\
r &= \dot\psi
\end{aligned}
```

Body acceleration:

```math
\dot\nu=R_3(\psi)^T\ddot z+\dot R_3(\psi)^T\dot z
```

Expanded:

```math
\begin{aligned}
\dot u &= \cos\psi\,\ddot x+\sin\psi\,\ddot y+rv \\
\dot v &= -\sin\psi\,\ddot x+\cos\psi\,\ddot y-ru \\
\dot r &= \ddot\psi
\end{aligned}
```

Nominal generalized force:

```math
\tau_{\mathrm{nom}}
=
\begin{bmatrix}
\tau_u & \tau_v & \tau_r
\end{bmatrix}^{T}
=\theta_{\tau,\mathrm{nom}}(z,\dot z,\ddot z)
=M\dot\nu+C_{\mathrm{nom}}(\nu)\nu+D_{\mathrm{nom}}(\nu)
```

The implementation uses:

```math
M=
\begin{bmatrix}
m & 0 & 0 \\
0 & m & 0 \\
0 & 0 & I_z
\end{bmatrix}
```

```math
C_{\mathrm{nom}}(\nu)\nu=
\begin{bmatrix}
-mvr \\
mur \\
0
\end{bmatrix}
```

```math
D_{\mathrm{nom}}(\nu)=
\begin{bmatrix}
d_u u+d_{uu}|u|u \\
d_v v+d_{vv}|v|v \\
d_r r+d_{rr}|r|r
\end{bmatrix}
```

Substituting the body acceleration into the nominal force expression cancels
the Coriolis terms in surge and sway. Therefore the dense-penalty code uses:

```math
\begin{aligned}
\tau_u &=
m(\cos\psi\,\ddot x+\sin\psi\,\ddot y)
+d_u u+d_{uu}|u|u \\
\tau_v &=
m(-\sin\psi\,\ddot x+\cos\psi\,\ddot y)
+d_v v+d_{vv}|v|v \\
\tau_r &=
I_z\ddot\psi+d_r r+d_{rr}|r|r
\end{aligned}
```

Sway-force bound:

```math
|\tau_v|\le\bar\tau_v
```

Thruster mapping:

```math
T_L=\frac12\left(\tau_u-\frac{\tau_r}{l}\right),\qquad
T_R=\frac12\left(\tau_u+\frac{\tau_r}{l}\right)
```

Thruster bounds:

```math
T_{\min}\le T_L\le T_{\max},\qquad
T_{\min}\le T_R\le T_{\max}
```

In the current live controller configuration, `T_min=-100 N` and
`T_max=100 N` unless overridden by parameters.

## 3. MINCO-S3NU parameterization

Each piece is a fifth-order polynomial:

\[
z_i(s)=c_{i,0}+c_{i,1}s+c_{i,2}s^2+c_{i,3}s^3+c_{i,4}s^4+c_{i,5}s^5.
\]

Let

\[
C_i=\begin{bmatrix}
c_{i,0}^T\\
c_{i,1}^T\\
c_{i,2}^T\\
c_{i,3}^T\\
c_{i,4}^T\\
c_{i,5}^T
\end{bmatrix}\in\mathbb R^{6\times3}.
\]

Define basis vectors:

\[
b_0(s)=\begin{bmatrix}1\\s\\s^2\\s^3\\s^4\\s^5\end{bmatrix},\quad
b_1(s)=\begin{bmatrix}0\\1\\2s\\3s^2\\4s^3\\5s^4\end{bmatrix},
\]

\[
b_2(s)=\begin{bmatrix}0\\0\\2\\6s\\12s^2\\20s^3\end{bmatrix},\quad
b_3(s)=\begin{bmatrix}0\\0\\0\\6\\24s\\60s^2\end{bmatrix}.
\]

Then

\[
z_i(s)=C_i^Tb_0(s),\quad
\dot z_i(s)=C_i^Tb_1(s),\quad
\ddot z_i(s)=C_i^Tb_2(s),\quad
z_i^{(3)}(s)=C_i^Tb_3(s).
\]

MINCO outer variables are the intermediate points and time variables:

\[
q=[q_1,\ldots,q_{M-1}],\qquad q_i\in\mathbb R^3.
\]

For fixed total time, use

\[
T_i=T_s\frac{\exp(\theta_i)}{\sum_{j=1}^{M}\exp(\theta_j)}.
\]

The outer variable is

\[
\xi=\begin{bmatrix}q\\\theta\end{bmatrix}.
\]

Polynomial coefficients are **not** optimized. They are generated by

\[
A(T)c=b(q,H,G),
\]

where

\[
H=[z_0,\dot z_0,\ddot z_0],\qquad
G=[z_f,\dot z_f,\ddot z_f].
\]

## 4. Initial guess and time allocation

### 4.1 What GCOPTER does

GCOPTER first computes a shortest spatial path through the corridor, splits each path segment according to a length-per-piece rule, and then initializes intermediate points by uniformly subdividing the path. Time allocation is proportional to subsegment length divided by an allocation speed.

In code, GCOPTER computes `pieceIdx` from path segment lengths divided by `lengthPerPiece`, adds one piece per segment, sums it into `pieceN`, and then calls `setInitial(shortPath, allocSpeed, pieceIdx, points, times)`. Its `setInitial` routine subdivides each path segment into `l` pieces, places intermediate points at `a + c*m`, and sets each subpiece time to `c.norm()/speed`.

### 4.2 Our initialization policy

For the first no-obstacle/local-terminal implementation:

1. Build an initial geometric path from start to local terminal.
2. If no front-end path exists, use the straight line in \((x,y)\) and unwrap yaw between \(\psi_0\) and \(\psi_f\).
3. Choose \(M\) pieces.
4. Set intermediate points by linear interpolation:

\[
q_i^{(0)}=(1-\alpha_i)z_0+\alpha_i z_f,
\qquad
\alpha_i=\frac{i}{M}.
\]

Yaw must be unwrapped before interpolation.

5. Choose total time. For fixed total time:

\[
T_s=\gamma\frac{L}{u_{\mathrm{ref}}},\qquad \gamma\ge1,
\]

where

\[
L=\sum_i\|p_{i+1}-p_i\|.
\]

6. Distribute times by segment length:

\[
T_i^{(0)}=T_s\frac{\Delta L_i+\epsilon_L}{\sum_{j=1}^{M}(\Delta L_j+\epsilon_L)}.
\]

For straight-line equal subdivision, this reduces to uniform time:

\[
T_i^{(0)}=\frac{T_s}{M}.
\]

For free-total-time mode:

\[
T_i^{(0)}=\max\left(\frac{\Delta L_i}{u_{\mathrm{ref}}},T_{\min,seg}\right).
\]

7. Convert \(T_i^{(0)}\) to \(\theta_i^{(0)}\) if using the softmax fixed-total-time parameterization. One valid choice is

\[
\theta_i^{(0)}=\log T_i^{(0)}.
\]

The softmax is invariant to adding a constant to all \(\theta_i\), so this is sufficient.

Important: We do **not** need a separate Pontryagin solve for the initial polynomial coefficients. Given \(q^{(0)}\) and \(T^{(0)}\), MINCO itself generates the minimum-jerk analytic polynomial coefficients through its linear optimality system.

## 5. Penalty-form unconstrained MINCO problem

Define all continuous-time inequality constraints as

```math
g_m(y(t))\le0
```

where

```math
y(t)=
\begin{bmatrix}
z(t)^{T} & \dot z(t)^{T} & \ddot z(t)^{T}
\end{bmatrix}^{T}
```

Constraints include:

- sway force: \(\tau_v-\bar\tau_v\le0\), \(-\tau_v-\bar\tau_v\le0\);
- velocity bounds;
- acceleration bounds;
- actuator bounds for \(T_L,T_R\).

The current actuator inequality vector is:

```math
\begin{aligned}
g_T(y)=
\begin{bmatrix}
T_{\min}-T_L \\
T_L-T_{\max} \\
T_{\min}-T_R \\
T_R-T_{\max}
\end{bmatrix}
\le 0
\end{aligned}
```

Use dense quadrature penalty:

```math
P_g=\sum_{i=1}^{M}T_i\sum_{j=1}^{K}\omega_j\sum_m\phi_\mu(g_m(y_{ij})),
```

with

```math
s_{ij}=\alpha_jT_i,
\qquad
y_{ij}=
\begin{bmatrix}
z_i(s_{ij})^{T} &
\dot z_i(s_{ij})^{T} &
\ddot z_i(s_{ij})^{T}
\end{bmatrix}^{T}
```

A smooth positive violation penalty is

```math
\phi_\mu(g)=
\left[
\frac{1}{\mu}\log(1+\exp(\mu g))
\right]^2
```

Its derivative, used by the analytic dense-gradient implementation, is:

```math
\frac{d\phi_\mu}{dg}
=
2
\frac{\log(1+\exp(\mu g))}{\mu}
\frac{1}{1+\exp(-\mu g)}
```

The unconstrained problem solved by L-BFGS is

```math
\min_{q,\theta}\;\bar J(q,\theta)
=E(c(q,T),T)+J_{\mathrm{time}}(T)+\lambda_{\tau_v}P_{\tau_v}
+\lambda_\nu P_\nu+\lambda_aP_a+\lambda_TP_T
```

This is a smooth penalty relaxation of the original constrained problem, not a finite-weight exact equivalence.

## 6. Gradient structure

The current implementation computes analytic direct dense-penalty gradients
with respect to polynomial coefficients and segment times. Finite differences
are used only for tests and audits.

For one quadrature node, define:

```math
f(z,\dot z,\ddot z)
=
\sum_m \lambda_m \phi_\mu(g_m(z,\dot z,\ddot z))
```

and node gradients:

```math
g_z=\frac{\partial f}{\partial z},
\qquad
g_{\dot z}=\frac{\partial f}{\partial \dot z},
\qquad
g_{\ddot z}=\frac{\partial f}{\partial \ddot z}
```

For one polynomial segment:

```math
z(s)=B_0(s)C,\qquad
\dot z(s)=B_1(s)C,\qquad
\ddot z(s)=B_2(s)C,\qquad
z^{(3)}(s)=B_3(s)C
```

At \(s=\alpha T\):

```math
J_q=T\,\omega\,f(z(\alpha T),\dot z(\alpha T),\ddot z(\alpha T))
```

The direct coefficient gradient is:

```math
\frac{\partial J_q}{\partial C}
=
T\omega
\left(
B_0^{T}g_z
+B_1^{T}g_{\dot z}
+B_2^{T}g_{\ddot z}
\right)
```

The direct segment-time gradient at fixed coefficients is:

```math
\frac{\partial J_q}{\partial T}
=
\omega f
+T\omega\alpha
\left(
g_z^{T}\dot z
+g_{\dot z}^{T}\ddot z
+g_{\ddot z}^{T}z^{(3)}
\right)
```

The first term comes from differentiating the quadrature interval scale \(T\).
The second term comes from the moving local sample time \(s=\alpha T\).

The optimizer combines these dense-penalty gradients with the analytic jerk
energy gradients:

```math
g_c=\frac{\partial\bar J}{\partial c},
\qquad
g_T^{\mathrm{direct}}
=
\left.
\frac{\partial\bar J}{\partial T}
\right|_{c\;\mathrm{fixed}}
```

MINCO coefficients satisfy

```math
A(T)c=b(q,H,G)
```

Introduce the adjoint variable

```math
A(T)^T\lambda=g_c
```

Then

```math
\frac{\partial\bar J}{\partial q_i}
=
\lambda^T\frac{\partial b}{\partial q_i}
```

For time:

```math
\frac{\partial\bar J}{\partial T_i}
=g_{T_i}^{\mathrm{direct}}-
\lambda^T\left(\frac{\partial A}{\partial T_i}c\right)
```

assuming \(b\) has no explicit time dependence.

For fixed-total-time softmax:

```math
\frac{\partial T_i}{\partial\theta_j}=T_i(\delta_{ij}-\pi_j),\qquad
\pi_i=\frac{T_i}{T_s}
```

Thus

```math
\frac{\partial\bar J}{\partial\theta_j}=
\sum_i\frac{\partial\bar J}{\partial T_i}T_i(\delta_{ij}-\pi_j)
```

## 7. Codex implementation requirements

1. Implement strict `MINCO_S3NU`.
2. Do not optimize polynomial coefficients directly.
3. Outer variables are `inPs` and time variables.
4. Implement initialization using path subdivision and length-based time allocation, matching GCOPTER's approach.
5. Implement dense quadrature penalties for sway force, velocity, acceleration, and actuator bounds.
6. Use analytic dense-penalty gradients for active optimization. Finite
   differences are allowed only for tests and gradient audits.
7. Add continuation parameters:
   - `tau_v_bound` starts large and can be reduced;
   - penalty weights start modest and can be increased.
8. Diagnostics must report:
   - PVA boundary residual;
   - continuity residual;
   - rms and max absolute `tau_v`;
   - max velocity and acceleration constraint violation;
   - max actuator constraint violation;
   - segment times;
   - gradient check error.
9. First implementation should use no obstacle/corridor. Obstacles are added after MINCO reference tracks correctly with NMPC.
10. Current runtime integration is one-shot local MINCO reference generation;
    continuous online replanning is a future phase, not a completed feature.
